# Agent d’intelligence artificielle utilisé

## 1. Informations générales

- **Nom de l’agent :** ChatGPT,claud AI (OpenAI)
- **Sujet :** Workshop 4 — Développement d’une application Flutter en temps réel avec Supabase
- **Langages et technologies :** Dart, Flutter, Provider et Supabase
- **Objectif :** Comprendre les étapes du TP, faciliter le développement de l’application et vérifier son fonctionnement.

## 2. Utilisation de l’intelligence artificielle

J’ai utilisé ChatGPT pour m’accompagner dans la réalisation du Workshop 4 et mieux comprendre les différentes étapes du développement de l’application Waiting Room.

ChatGPT m’a aidée à :

- Comprendre le fonctionnement de Supabase et son rôle dans le stockage des données en ligne.
- Configurer la connexion entre l’application Flutter et la base de données Supabase.
- Adapter le code Dart à la structure de la table `clients`.
- Utiliser Provider et `ChangeNotifier` pour gérer les données et actualiser l’interface utilisateur.
- Mettre en place la récupération initiale des clients et l’écoute des changements en temps réel avec les flux Supabase.
- Comprendre les méthodes d’ajout, de suppression et de passage au client suivant.
- Identifier et corriger des erreurs liées aux types de données, aux imports et à la configuration de Supabase Realtime.
- Tester le fonctionnement de l’application dans Chrome et vérifier la synchronisation des données entre plusieurs onglets.

## 3. Méthode de travail

Le travail a été réalisé progressivement. J’ai suivi les étapes du TP, étudié les explications proposées, adapté le code à mon projet et exécuté les commandes Flutter nécessaires pour vérifier son fonctionnement.

Lors des tests, j’ai rencontré un problème : les clients ajoutés depuis Supabase n’apparaissaient dans l’application qu’après l’actualisation de la page. Avec l’aide de ChatGPT, j’ai identifié la publication `supabase_realtime` dans le tableau de bord Supabase et vérifié la configuration de la table `clients`.

Cette démarche m’a permis de mieux comprendre l’importance de la configuration Realtime et de la communication entre la base de données et l’interface utilisateur.

## 4. Autre outil testé

J’ai également essayé d’utiliser Antigravity pour m’aider dans le développement. Cependant, son agent a rencontré une erreur qui ne m’a pas permis de poursuivre correctement le travail avec cet outil. J’ai donc continué avec ChatGPT pour obtenir des explications, analyser les problèmes rencontrés et avancer dans la réalisation du TP.

## 5. Bilan

L’utilisation de ChatGPT m’a permis de mieux comprendre les technologies utilisées dans le projet, de résoudre certaines difficultés techniques et de progresser dans le développement de l’application.

L’intelligence artificielle a été utilisée comme un outil d’assistance à l’apprentissage et au développement. J’ai appliqué les explications et les corrections proposées dans mon projet, puis vérifié le comportement de l’application à l’aide de tests.
