# Compte-rendu des discussions avec l'IA

## 1. Introduction

Pour réaliser le Workshop 3, j'ai utilisé ChatGPT pour m'aider à comprendre les étapes du TP et à travailler sur mon projet Flutter existant.

Le sujet du TP est l'utilisation de Provider pour gérer l'état de l'application et les tests avec la méthode TDD.

## 2. Travail réalisé avec l'IA

J'ai demandé à ChatGPT de m'expliquer le TP étape par étape et de m'aider à réaliser les modifications sans supprimer mon travail précédent.

Nous avons réalisé les tâches suivantes :

- Vérifier le projet Flutter et les tests existants.
- Vérifier l'installation du package Provider.
- Créer le fichier `queue_provider.dart`.
- Créer des tests pour vérifier le fonctionnement de la file d'attente.
- Modifier le fichier `main.dart` pour utiliser Provider.
- Ajouter le bouton « Next Client » pour passer au client suivant.
- Vérifier le code avec la commande `flutter analyze`.

## 3. Difficultés rencontrées

Au début, j'ai essayé d'utiliser Antigravity, mais son agent affichait une erreur et ne pouvait pas continuer.

J'ai donc poursuivi le travail avec ChatGPT, qui m'a guidée étape par étape.

## 4. Ce que j'ai appris

Grâce à ce travail, j'ai appris à :

- Utiliser Provider dans une application Flutter.
- Comprendre le rôle de `ChangeNotifier`.
- Utiliser `context.watch()` et `context.read()`.
- Gérer une file d'attente de clients.
- Écrire des tests pour vérifier le fonctionnement du code.
- Vérifier le code avec les outils de Flutter.

## 5. Conclusion

L'intelligence artificielle m'a aidée à mieux comprendre le TP et à avancer progressivement dans mon projet.

J'ai conservé les fonctionnalités principales de mon application précédente et ajouté la gestion de l'état avec Provider. Ce travail m'a également permis de comprendre l'importance des tests dans le développement d'une application.
